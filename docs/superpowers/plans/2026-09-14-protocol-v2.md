# Glyph Protocol v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Glyph's prepare→seal protocol with a practice/final two-phase protocol — practise on a visible validation set (queries capped at Q, up to 20 legal aggregate-score submissions), then answer a held-out test once — run through a Claude Agent SDK harness whose evaluated agent has Bash and file tools inside a bwrap sandbox behind a metering model gateway.

**Architecture:** The numpy-only data layer gains a `validation` split and a query-policy predicate; everything else is new code under `src/glyph/v2/`. Custom tools are exposed to the model through an in-process SDK MCP server sharing one `Session` object (instance, ledger, counters, phase). The whole Claude Code CLI runs inside a bwrap wrapper (`ClaudeAgentOptions.cli_path`) that hides the repo, GPUs and credentials and routes all model traffic through a host-side gateway that meters usage and pins the model.

**Tech Stack:** Python 3.11+, numpy (data layer), `claude-agent-sdk==0.2.152`, `aiohttp` (gateway), `anthropic[vertex]` (gateway upstream), bubblewrap 0.11.2, vLLM + transformers + peft (student, `train` arm only), pytest.

**Spec:** `docs/superpowers/specs/2026-09-14-protocol-v2-design.md` (on branch `protocol-v2`). Read it alongside this plan.

## File Structure

**Data layer (extended in place):**
- `src/glyph/data/config.py` — add `n_val`; keep `query_ood_policy` here as a plain constant tuple of valid values.
- `src/glyph/data/instance.py` — add `self.val`, `query_violation()`, and coverage helpers.
- `src/glyph/data/__init__.py` — export the new names.

**Protocol layer (new package `src/glyph/v2/`):**
- `session.py` — `Session`: the shared state object (instance, ledger, counters, phase, run dir, arm). No SDK, no I/O beyond the run dir.
- `answers.py` — the legality checker and scoring over an answer file. Pure; imports only `glyph.data`.
- `ledger.py` — v2 ledger: USD-by-kind + GPU/CPU seconds. (Replaces `budget.py` usage; `budget.py` itself is deleted in the migration task.)
- `tools.py` — the in-process MCP tool handlers (`query`, `submit`, `check_answers`, `finish_practice`, `build_dataset`, `train`, `student_infer`, `final_answer`) built from a `Session`.
- `student.py` — `train` arm host-side student wrappers around `glyph.train.sft` / `glyph.train.infer`, with the GPU caps.
- `gateway.py` — aiohttp unix-socket server: pins the model, meters usage, logs full requests, retries upstream.
- `bridge.py` — copied read-only into the sandbox; forwards `127.0.0.1:8787` → `/run/gw.sock`, then execs the CLI.
- `sandbox.py` — builds the bwrap wrapper script and the run workspace.
- `prompts.py` — the v2 system prompt and phase opening messages, plus the `README.md` written into `task/`.
- `harness.py` — the orchestrator: builds the run, drives `ClaudeSDKClient`, counts turns, switches phase, scores, writes the report.
- `report.py` — assembles the `ScoreReport` (reusing `seal`'s ceilings/headroom) and covariates.
- `cli.py` — `python -m glyph.v2 run --arm ... --preset ... --seed ...` and a `grid` subcommand.

**Kept from v1 (adapted):** `seal.py` (ceilings/headroom/scoring helpers only), `trace.py` (writer), `train/sft.py`, `train/infer.py`, all of `data/` except the additions, `scripts/`.

**Deleted in the migration task (Task 16):** `arms/`, `agent/`, `worker.py`, `sandbox.py` (v1), `budget.py`, and their tests; the `SealedArtifact`/`answer_with` parts of `seal.py`.

**Tests:** one `tests/v2/test_*.py` per module, plus `tests/test_instance.py` / `tests/test_data_boundary.py` extensions.

```python
    def _make_val(self, rng) -> list["TestItem"]:
        cfg = self.cfg
        seen = {a for a, _ in self.demos} | {t.expr_src for t in self.test}
        out: list[TestItem] = []
        stall = 0
        while len(out) < cfg.n_val:
            if stall >= _STALL_LIMIT:
                raise GenerationFailed(
                    "val", len(out), cfg.n_val,
                    _diagnose(rng, cfg, cfg.demo_max_depth, self.held_pairs, None, 1))
            e = _sample_constrained(rng, cfg, cfg.demo_max_depth,
                                    forbid=self.held_pairs, require=None, min_depth=1)
            if e is None:
                stall += 1; continue
            src = render(e, cfg)
            if src in seen:
                stall += 1; continue
            seen.add(src)
            out, stall = out, 0
            o, log = self.P.eval_logged(e)
            out.append(TestItem(src, self._render_out(o), "val",
                                frozenset(log.unary), frozenset(log.binary)))
        return out
```

```python
    def _canon(self, src: str) -> str | None:
        try:
            return render(parse(src, self.cfg), self.cfg)
        except Exception:
            return None

    def query_violation(self, expr_src: str, policy: str = "strict") -> str | None:
        canon = self._canon(expr_src)
        if canon is None:
            return None                      # malformed: charged, not refused
        if self._val_srcs is None:
            self._val_srcs = {self._canon(t.expr_src) for t in self.val}
            self._test_srcs = {self._canon(t.expr_src) for t in self.test}
        if canon in self._val_srcs:
            return "is_validation_item"
        if canon in self._test_srcs:
            return "is_test_item"
        if policy == "open":
            return None
        e = parse(expr_src, self.cfg)
        if op_pairs(e) & self.held_pairs:
            return "contains_held_out_pair"
        if depth(e) > self.cfg.demo_max_depth:
            return "deeper_than_demos"
        return None
```
